# Claude CodeのVSCode拡張が使いやすいよ

皆様、Claude Code使ってますか？

CLIで利用されている方が大多数だと思いますが、VSCodeの拡張も悪くないよ、というお話です。

いつのころからか、左右にパネルが出るような構成になっています。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/4b7544a7-a7b8-4664-8e72-44722437fd72.png)

右側が通常（？）のチャット欄で左が過去のセッション一覧みたいな感じです。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/ebd54eb3-b9eb-4a9c-83ff-9768f22daf3e.png)

左側にある「New session」をクリックするとメインのコードエディター部分にチャット欄がタブとして表示されます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/680f12ce-511f-41c0-a2d7-e5f7a842aa58.png)

連打すると量産できますし

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/ee6e9033-02c4-47e4-a00a-72d7fc66ccc6.png)

タイル状に配置したりできます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/98052458-6a82-4d73-9bf1-4bf7275cf843.png)

モードとか設定とか、マウスでポチポチ設定できます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/756deb2d-5d83-44d3-855d-7e422d557f78.png)

MCPサーバーの設定とかも、グラフィカルでわかりやすい。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/f97ae7c0-80f3-414b-8a1b-5c1ef1204894.png)

プランモードでテトリスを作ってみましょう。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/024986b3-2411-41e7-9be4-2308f5d9d145.png)

そういえば、Windowsですがいい感じにPowerShellを実行してくれます。
そういえば、別途`claude`をインストールもしておらず、VSCode拡張をインストールしただけです。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/c1183460-1a9b-44eb-b8c0-a1b62edc5a1c.png)

ツール実行するか確認されるとこんな感じです。

２つ目の選択肢は、yesを覚えさせて実行するやつですが、「this project (just you)」のところがクリックできます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/5022c99e-0636-4ee1-af5f-1d3949c741f5.png)

「all projects」になりました。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/bfd288e5-1c62-45d0-9221-f99ac42d8303.png)

もう一回クリックすると「this project (shared)」「this session」と切り替わります。
要は、どの設定として記憶するかを選べます。これが地味に便利です。

プランが作成されたら、真ん中のエディター部分に表示されます！

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/779b1def-1dda-44f0-a08d-bdb76e50a24c.png)

:::note
これでやっと読む気になりますね。（CLIで使ってる人、どうせ読んでないでしょ？白状しなさい！！）
:::

プランの文字はマウスで選択してコメントが追加できます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/c1e56abc-dd9c-422a-9a73-80fa8d6aa7f6.png)

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/bfbc8bf1-f846-4559-a4ac-9b94170125b7.png)

コメントは複数つけられます。コメントが終わったらフィードバックできます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/006640f8-1e79-4875-abc4-92648d53974b.png)

追加で質問されたりします。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/f565f0fe-211b-45c1-a892-3a3b2135b71f.png)

コメントを反映したプランが提示されます。問題なければ実装に移ります。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/88e4fa86-d463-43c4-8720-34dd3d0948d2.png)

テトリスできた！

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/41574/34c1ac69-9c70-42f0-bd30-36bfac3a920c.png)


以上です。

使いやすいですよ
